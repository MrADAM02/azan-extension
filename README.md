# Azan Tab – Prayer Times

A Chrome / Edge (Manifest V3) extension that replaces the New Tab page with a prayer-times dashboard. It also has a toolbar popup, azan audio, notifications, the Hijri date, Qibla direction and weather.

Built with [WXT](https://wxt.dev), React, TypeScript and Tailwind. Prayer times are calculated locally with [adhan](https://github.com/batoulapps/adhan-js), so they work offline.

## Development

```bash
npm install
npm run dev        # opens Chrome with the extension loaded and hot reload
npm run build      # production build in .output/chrome-mv3
npm run zip        # store-ready zip
npm run compile    # type-check
```

To try it in **Edge**, run `npm run build`, open `edge://extensions`, turn on *Developer mode*, then click *Load unpacked* and select `.output/chrome-mv3`.

## Structure

| Path | Purpose |
|---|---|
| `entrypoints/newtab/` | New Tab dashboard and first-run onboarding (location + method) |
| `entrypoints/popup/` | Toolbar popup: next prayer, countdown, today's times, mute / stop |
| `entrypoints/options/` | Full settings page |
| `entrypoints/background.ts` | Service worker: schedules `chrome.alarms` for the next 48 h, shows notifications, starts the azan |
| `entrypoints/offscreen/` | Hidden page that plays audio (MV3 service workers can't) |
| `lib/schema.ts` | Settings types and defaults (pure, so it can be tested in Node) |
| `lib/settings.ts` | `chrome.storage.sync` wrapper |
| `lib/prayer.ts` | adhan wrapper: times in the city's timezone, current/next prayer, Qibla |
| `lib/location.ts` | Geolocation + reverse geocode (BigDataCloud) + city search (Open-Meteo) |
| `lib/weather.ts` | Open-Meteo current weather, cached for 30 min |
| `lib/blobStore.ts` | IndexedDB storage for uploaded azan audio and background image |
| `lib/i18n.ts` | English / Arabic strings (RTL handled in `lib/hooks.ts`) |

## Azan audio

| File | What | Source / license |
|---|---|---|
| `public/audio/madinah-full.ogg` | Full azan recorded at the Prophet's Mosque, Madinah (3:06) | [ejaz215 via Freesound / Wikimedia Commons](https://commons.wikimedia.org/wiki/File:33937_ejaz215_call-to-prayer-from-the-prophet-s-mo.ogg), CC BY 3.0 |
| `public/audio/madinah-short.ogg` | Same recording, ending after the opening takbir (0:34). This is the default sound | same |
| `public/audio/chime.wav` | Gentle chime | generated by `node scripts/gen-chime.mjs` |

The Madinah files were converted to mono Opus (~57 kbps) and normalized by `scripts/encode-azan.py`. CC BY requires the credit, which is shown under *Sources & credits* in Settings; keep it. No openly licensed Fajr azan (with "الصلاة خير من النوم") was found, so users can upload their own Fajr azan. Do not bundle recordings from collections without a clear license (for example re-uploads of famous muezzins or Haram broadcasts).

## Quran, hadith and adhkar content

`public/content/*.json` is generated by `node scripts/build-content.mjs`. The script downloads the sources (cached in `.content-cache/`), copies the text verbatim, verifies counts and references, and writes the JSON. To change which Quran passages appear, edit `SELECTION` in the script and run it again.

| Content | Source | License |
|---|---|---|
| Quran Arabic (Uthmani) | [Tanzil](https://tanzil.net) | CC BY 3.0. Must stay verbatim; keep the credit and link |
| Quran English | Saheeh International via Tanzil | Non-commercial use only |
| Hadith (Nawawi 40, Qudsi 40), Arabic | [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) | Unlicense |
| Morning/evening adhkar, Arabic | [Morning-And-Evening-Adhkar-DB](https://github.com/Seen-Arabic/Morning-And-Evening-Adhkar-DB) | MIT |

Hadith and adhkar are shown in Arabic only. The English translations in those datasets come from publishers whose redistribution terms are unclear. If the extension ever becomes paid, the Saheeh International translation needs the publisher's permission.

## Before publishing

- Replace the placeholder WXT icons in `public/icon/`.
- Write a privacy policy. The location is stored only in browser sync storage, and coordinates are sent only to Open-Meteo (weather/search) and BigDataCloud (city name).
- Keep the Open-Meteo attribution link (CC BY 4.0). It is shown in the New Tab footer.
